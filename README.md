# Space Quiz

A dependency-free, single-file quiz about space exploration. It includes ten questions, score and progress tracking, answer feedback, and a results screen.

## Run locally

Open `index.html` in a modern web browser. No installation, build step, or server is required.

## Deployment

The GitHub Actions workflow in `.github/workflows/deploy-pages.yml` publishes the quiz to GitHub Pages whenever changes are pushed to `main`.
